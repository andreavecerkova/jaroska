Co je rekurze?

Rekurze znamená, že funkce volá sama sebe, ale vždy na menší (jednodušší) úlohu. Každá rekurzivní funkce potřebuje dvě věci:

  • základní případ (zarážku): úlohu tak malou, že ji vyřešíme přímo, bez dalšího volání,
  • rekurzivní krok: převedení úlohy na menší úlohu stejného druhu.

Příklad: n! je n krát (n−1)!, a 0! je rovno 1.

def factorial(n):
    if n == 0:                    # základní případ: vyřešíme přímo
        return 1
    return n * factorial(n - 1)   # rekurzivní krok: menší úloha

Jak úlohy řešit

  1. Stáhněte si soubor s úlohou (nebo zkopírujte kód do svého editoru).
  2. Místo pass napište funkci tak, aby fungovala podle zadání v komentáři.
  3. Spusťte soubor. Pokud se nevypíše nic, všechny testy prošly. Pokud uvidíte AssertionError, některý test selhal. Řádek u chyby ukazuje který.

Tip: k řešení použijte rekurzi. Hvězdičky u úloh značí obtížnost.
